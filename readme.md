
# Retail Sales Analysis: From Charts to Decisions

## Project Overview
A Retail Sales Data Analysis project using Python.
This project analyzes retail transactions from 2023-2024
across four regions of India.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- SciPy
- Streamlit
- Jupyter Notebook

## Features
- Data Cleaning
- Exploratory Data Analysis
- Statistical Analysis
- Sales and Profit Analysis
- Customer Analysis
- Interactive Dashboard

## How to Run

Install dependencies:

pip install -r requirements.txt

Run Jupyter Notebook:

jupyter notebook Source_Code_v2.ipynb

Run Dashboard:

streamlit run Dashboard_v2.py
